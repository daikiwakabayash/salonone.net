# ファーストビュー画像の差し替え

トップページ（ファーストビュー）の画像は、このフォルダ内の2枚を
**同じファイル名で上書き**するだけで反映されます。コードの編集は不要です。

| ファイル名 | 用途 | 推奨サイズ（目安） |
|---|---|---|
| `hero-pc.png` | PC・タブレット用（横長） | 幅 1920px 前後 / 比率 16:9〜2:1 |
| `hero-mobile.png` | スマートフォン用（縦長） | 幅 900px 前後 / 比率 3:4〜9:16 |

## 手順
1. ご用意した画像を上記のファイル名にリネーム
2. この `assets/` フォルダ内の同名ファイルを置き換える（上書き）
3. ページを再読み込みすると反映されます

## 補足
- 画面上部には透過のヘッダー（ロゴ・メニュー）が重なります。
  画像の上部 80px ほどは**ロゴや重要な要素を避けて**書き出すと、
  ヘッダーと自然に組み合わさります。
- `.jpg` / `.webp` を使いたい場合は、`index.html` の
  `<picture>` 内の `src` / `srcset` の拡張子も合わせて変更してください。
- スマホ用画像（`hero-mobile.png`）が未用意の場合でも、
  PC用画像が代替表示されるようにしておくと安全です。
