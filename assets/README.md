# ファーストビュー画像の差し替え

トップページ（ファーストビュー）の画像は、このフォルダ内の2枚を
**同じファイル名で上書き**するだけで反映されます。コードの編集は不要です。

| ファイル名 | 用途 | 現在のサイズ |
|---|---|---|
| `hero-pc.png` | PC・タブレット用（横長） | 1695 × 928 |
| `hero-mobile.png` | スマートフォン用（縦長） | 863 × 1822 |

## 手順
1. 用意した画像を上記のファイル名にリネーム
2. この `assets/` フォルダ内の同名ファイルを置き換える（上書き）
3. ページを再読み込みすると反映されます

## ヘッダーについて
- サイト共通のヘッダーは**ファーストビューの上では非表示**になり、
  画像を過ぎてスクロールすると白いヘッダーが現れます。
- そのため、**ロゴ・メニュー・ボタンは画像内に含めてOK**です（現在の画像はその想定）。

## 画像内ボタンを「クリックできる」ようにする当たり判定
画像に描かれたボタンの上に、透明のリンク（ホットスポット）を重ねています。
画像のボタン位置を変えた場合は、`index.html` 内の以下のクラスの
`left / top / width / height`（％）を調整してください。

| クラス | 対象 | リンク先 |
|---|---|---|
| `.hot-pc-logo` / `.hot-m-logo` | ロゴ | ページ先頭 |
| `.hot-pc-doc` / `.hot-m-doc` / `.hot-m-doctop` | 資料ダウンロード | `#contact` |
| `.hot-pc-demo` / `.hot-m-demo` | デモ画面を見る | `https://salonone.net/` |
| `.hot-m-menu` | ハンバーガー（モバイル） | メニューを開く |

> `*-pc-*` はPC用画像、`*-m-*` はモバイル用画像に対応します。

## 補足
- `.jpg` / `.webp` を使う場合は、`index.html` の `<picture>` 内の
  `src` / `srcset` の拡張子も合わせて変更してください。
